# Study frames — record

Every file in this folder is a **noncanonical visual study artefact**. None of
them is approved design, a specification, or a decision.

The study artefact rule in `../TruLura_Study05_Brief.md` (section 2) requires a
visible `VISUAL STUDY nn · NONCANONICAL` watermark on every frame. The watermark
is what stops a render being mistaken for approved design, so a frame that has
lost it is recorded here by name.

## The unlabelled frame

**`TruLura_Home_Variant_PhoneCapture_NoStudyLabel.jpg` is unclassified and
noncanonical. It is not an approved TruLura render.**

- It is a phone capture of a Home variant with a TruLura wordmark, taken in a
  photo viewer. The viewer's own controls cover the top and bottom of the
  image, and the study footer is cut off.
- So the frame carries no classification of its own. This is the artefact rule
  failing as predicted: the label did not survive the crop.
- Do not cite it as evidence of a design decision, and do not infer which study
  it belongs to from how it looks.
